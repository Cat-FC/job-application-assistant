# Changelog

## 1.1.0 - 2026-10-31

- Add privacy and data-minimization guidance for resumes, portfolios, web searches, and diagnostic snapshots.
- Separate legal or administrative requirements from employer screening rules and replaceable preferences.
- Avoid rejecting applications solely because years of experience or education fall below a preference.
- Add standard and detailed output modes to control report length.
- Add a stable, privacy-safe YAML diagnostic snapshot for reassessment in a new conversation.
- Add ten behavior regression scenarios covering technical, nontechnical, regulated, contradictory, early-stop, privacy, and reassessment cases.
- Add a zero-dependency release validator and GitHub Actions validation workflow.

## 1.0.0 - 2026-10-31

- Initial public release with adaptive one-question-at-a-time assessment.
- Add evidence-based gap analysis, prioritized learning roadmaps, verified resource guidance, and progress reassessment.
